\# AGENTS.md



\## Project

\- Build the game as a simple, maintainable HTML/CSS/JavaScript project.

\- Keep the implementation proportional to the assignment; do not over-engineer.



\## Code Quality

\- Follow DRY: do not duplicate logic.

\- Keep functions small and focused on one responsibility.

\- Use meaningful names for variables, functions, and files.

\- Avoid magic numbers and strings; centralize meaningful game constants.

\- Separate game logic, rendering, input handling, and UI/state management where practical.

\- Prefer simple solutions over unnecessary abstractions, frameworks, or dependencies.

\- Do not add libraries unless they provide a clear requirement-related benefit.



\## Video.js

\- Use the official Video.js documentation and project guidance when implementing Video.js.

\- Prefer the current, version-correct Video.js API rather than relying on outdated examples.



\## Verification

\- After making changes, verify that the game runs correctly.

\- Check for console errors and broken functionality.

\- Before finishing, review the implementation for duplicated logic, unnecessary complexity, magic values, and unrelated changes.
